# Changelog

## 0.2

- While the calendar loads after a new address, the menu says "Fetching collection days…" instead of "No collection days known"
- An unknown waste type without a description shows its code as RAD sends it ("KCA")
- At noon the icon moves on together with the menu, no longer up to five minutes later
- An invalid address keeps what you typed: the dialog opens again with it

## 0.1

First release.

- Menu bar icon for the next collection: PMD (bin bag), organic waste, paper or residual waste
- Menu with the next four collections
- Notification the evening before at 19:00
- RAD's calendar via Ximmio, holiday shifts included; postcode and house number on first launch
- Dutch or English: follows macOS, or pick one in the menu
- macOS 12 or later, Apple Silicon and Intel

Install: open `Cliko.dmg`, drag Cliko to Applications, then run `bash /Volumes/Cliko/install.sh` in Terminal.
